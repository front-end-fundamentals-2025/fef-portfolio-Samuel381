PROJECTS

The 'Tote' project is an e-commerce website for selling tote bags. The website allows users to browse different designs, view product details, and make purchases. T he focus of the project was on creating a clean and functional interface that ensures a smooth shopping experience. This project helped me explore aspects of web design related to e-commerce, including product presentation, navigation, and user interaction.
